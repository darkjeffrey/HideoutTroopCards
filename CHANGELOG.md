# Changelog

## 1.0.0
- Weapon icons on hero cards in the troop selection screen (hideout attacks and lord's hall fights): one icon per kind of weapon, hover for the item name.
- Optional icons for thrown weapons, quivers and regular troops.
- The party screen's sort control (Type, Name, Count, Tier, Custom) with an ascending/descending arrow; heroes stay on top and the last sort is remembered.
- Optional auto-pick of every healthy companion when the screen opens.
- Mod Configuration Menu options for all of the above, plus debug messages.
